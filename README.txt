ARYAN SHRIMALI — PERSONAL PORTFOLIO
===================================

FILES (keep all four in the same folder)
- index.html        : content and structure
- style.css         : design, responsive layout, print styles
- solar-tracker.mp4 : your solar tracker video
- award-photo.jpg   : photo from the science exhibition prize distribution

HOW TO VIEW
Double-click index.html. For editing, open the folder in Visual Studio Code.

STILL OPTIONAL
- When you get the certificate, add it to the Achievements section and remove

SAVE AS PDF (video is skipped automatically)
Open index.html in Chrome/Edge > Ctrl+P > Save as PDF > A4 > enable
"Background graphics". The video box is hidden in print so the PDF shows
only the project details.

NOTES
